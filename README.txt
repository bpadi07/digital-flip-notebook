AARVI COLLECTION — PREMIUM BELAGAVI FLIPBOOK (26 PAGES)
=======================================================

A responsive, premium digital jewellery catalogue made with HTML, CSS and JavaScript. It includes one standalone front cover, 12 two-page spreads (24 interior pages) and one standalone closing cover: 26 pages total.

OPEN IN VISUAL STUDIO CODE
--------------------------
1. Download and extract the ZIP.
2. Open Visual Studio Code.
3. Choose File > Open Folder and select Aarvi_Jewellers_Premium_Belagavi_26Page.
4. Open index.html.
5. Recommended: install the Live Server extension, right-click index.html and choose Open with Live Server.
   The site has no build step and its images/music are bundled locally.

COVER AND PAGE NAVIGATION
-------------------------
* The front cover is a single centered page: AARVI COLLECTION, “Every jewel tells an amazing story”, SWIPE TO CONTINUE and DESIGNED BY CVIS.
* The Previous and Next arrows sit beside the book. Next opens the first spread; Previous from the first spread returns to the front cover.
* Previous from the first spread runs a dedicated front-cover reset: it clears animation overlays and stale transition locks, then restores the single-page cover. It also interrupts the cover-opening animation if Previous is clicked quickly.
* 26 pages total: page 01 front cover, pages 02–25 in 12 spreads, page 26 closing cover.
* Interior spreads use alternating champagne, blush, sage, plum, lagoon and terracotta paper palettes. Product spreads alternate whether the product text or model image is on the left/right page.
* Included controls: home/brand logo, contents, WhatsApp, call, zoom, fullscreen, auto flip, page-turn sound, thumbnails, share, music selection, volume, keyboard navigation and mobile swipe.

AUTOPLAY NOTE
-------------
The site requests autoplay on load and retries on the visitor's first click/tap or key press. Modern browsers may block audible autoplay until a user gesture; this is a browser policy the website cannot override. The music and volume controls remain available, and playback can begin immediately after the first interaction.
